# My Portfolio

A Vite + React portfolio with a Supabase admin backend. Content is driven by this README — edit any section below and push to GitHub; the live site picks it up automatically.

## Local Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and add your Supabase keys (optional — the site falls back to this README if Supabase is not configured).
3. Run the SQL in `supabase/schema.sql` in the Supabase SQL Editor.
4. Start: `npm run dev`

## Deployment

Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to your Vercel project settings, then deploy normally.
